# C# START

Интерактивный курс по первым шагам в программировании и C#.

## Запуск проекта

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test -- --run
npm run build
```

Проект работает как статический учебный сайт и подходит для публикации на любом хостинге статических файлов.
