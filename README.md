# C# START

Интерактивный курс по первым шагам в программировании и C#.

## Запуск проекта

```bash
npm install
npm run dev
```

## Проверка

```bash
npm test -- --run
npm run build
```

## Компилятор C#

Лаборатория отправляет код и необязательный стандартный ввод в защищённый Judge0 CE sandbox через серверный endpoint `api/run-csharp.ts`. Поэтому для настоящего запуска кода публикуйте проект на Vercel или запускайте его локально через `vercel dev`; обычный статический хостинг покажет интерфейс, но не сможет выполнить серверный endpoint.
