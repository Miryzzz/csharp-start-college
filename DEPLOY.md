# Как запустить и развернуть «Погружение в C#»

## Локальный запуск

Нужен Node.js 18 или новее.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://localhost:5173`).

Проверка проекта:

```bash
npm test -- --run
npm run build
```

## Развёртывание на Vercel

1. Загрузите проект в GitHub и импортируйте репозиторий в Vercel.
2. Оставьте стандартные настройки для Vite; если Vercel попросит их вручную, укажите `npm run build` и папку `dist`.
3. После публикации сайт будет доступен как статический учебный курс.

## Развёртывание интерфейса на статическом хостинге

Сайт собирается в папку `dist`, поэтому его можно разместить на Cloudflare Pages, Netlify, GitHub Pages или обычном веб-сервере.

1. Загрузите содержимое этой папки в свой GitHub/GitLab репозиторий или откройте её в выбранном хостинге.
2. Укажите команду сборки `npm run build`.
3. Укажите папку результата `dist`.
4. Если хостинг просит версию Node.js, выберите 18 или новее.

Для ручной загрузки сначала выполните `npm install` и `npm run build`, затем загрузите **содержимое** папки `dist` в корень сайта.

## Пример: Cloudflare Pages

Создайте Pages-проект из Git-репозитория и задайте:

- Build command: `npm run build`
- Build output directory: `dist`
- Node.js: `18` или новее

После каждого `git push` Cloudflare Pages будет пересобирать сайт автоматически.

## Важно

Файл `.openai/hosting.json` нужен для исходного проекта в Sites и не требуется для обычного статического хостинга. Для независимого развёртывания его можно оставить в исходниках или удалить перед публикацией — приложение от него не зависит.
